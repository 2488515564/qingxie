# 轻卸图标

由内置 image_gen 图像生成工具制作。图像保留透明通道；安装包使用 GdkPixbuf 输出标准尺寸，不修改设计内容。

最终生成提示词：

Use case: logo-brand. Asset type: production Ubuntu desktop application launcher icon for Qingxie (轻卸), a simple friendly software uninstaller whose existing UI accent is burnt orange #E95420. Create ONE polished square app icon, 1024x1024. Icon silhouette is a rounded square tile in warm Ubuntu orange with subtle tonal depth, containing a bold minimal ivory-white feather angled from lower left to upper right; a small clean negative-space minus cutout subtly suggests removing unwanted software. Feather must read as lightness, not a broom. Simple strong geometric silhouette, restrained modern GNOME/Linux desktop icon craftsmanship, crisp edges, broad shapes legible at 32px. Centered tile fills about 88% of canvas. Transparent outside the rounded-square tile with genuine alpha. No text, letters, typography, watermark, mockup, perspective, checkerboard pattern, scene, extra floating objects, or elaborate tiny details. Single isolated icon only.
